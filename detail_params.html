[OHHEE] 미드저니의 프롬프트 기초, 파라미터

Midjourney · 파라미터 레퍼런스

파라미터 사용법: 모든 파라미터는 프롬프트의 가장 마지막 부분에 한 칸 띄어쓰기 후 작성합니다.

예시 a cat --ar 16:9 --v 8.2

01
구조 및 화면 제어 Structure & Layout
이미지의 형태와 구성 요소를 결정하는 가장 기초적인 파라미터입니다
파라미터설명값의 범위활용 팁
--aspect
--ar		 이미지의 가로세로 종횡비 설정 1:1, 16:9, 9:16 등 룩북 작업 시 4:5(인스타그램)나 2:3을 추천
--no 이미지에서 제외하고 싶은 요소 입력 텍스트
(예: --no text)		 불필요한 텍스트가 생성되는걸 막거나 특정 사물 생성을 미리 방지
--tile 상하좌우가 이어지는 패턴 이미지 생성 (값 없음) 패브릭 디자인, 벽지 패턴 제작 시 유용
02
스타일 및 미학 제어 Style & Aesthetics
이미지의 예술적 표현 강도와 개성을 조절합니다
파라미터설명값의 범위활용 팁
--stylize
--s		 미드저니 고유의 예술적 화풍 강도 0 ~ 1000
(기본 100)		 높을수록 화려하지만 프롬프트 반영력은 낮아짐
--chaos
--c		 생성되는 4장의 결과물 간의 다양성(의외성) 정도 0 ~ 100 c 값이 높을수록 생성되는 4장의 결과물이 서로 연관성 없이 다양하게 나옴
--weird
--w		 독특하고 기괴한 느낌 추가 0 ~ 3000 아방가르드하거나 실험적인 비주얼에 적합
--quality
--q		 이미지 렌더링에 소요되는 시간(디테일), 디테일의 정밀도 결정 0.25, 0.5, 1
(기본 1)		 q 값을 0.25로 낮추면 단순화된 텍스쳐로 빠르게 이미지를 생성. 해상도와는 무관
03
모델 버전 및 엔진 Model Selection
어떤 뇌(엔진)를 사용할지 결정합니다
파라미터설명주요 옵션활용 팁
--v 미드저니 모델 버전 설정 5.2, 6.0, 8.2 등 현재 정식 출시된 최신 엔진은 v 8.2NEW 입니다.
--niji 애니메이션/일러스트 특화 모델 — 키치한 그래픽이나 캐릭터 작업 시 사용
--style raw
--raw		 AI의 개입을 줄이고 프롬프트에 충실 --raw --raw 만 입력해도 작동. 미드저니 AI의 개입을 줄이고 프롬프트에 충실한 이미지를 생성하고 싶을 때 사용
04
고급 참조 및 개인화 Advanced Reference
파라미터설명값의 범위 / 사용법활용 팁
--sref Style Reference
특정 이미지의 화풍 복사		 이미지 URL 특정 이미지를 넣고 톤앤매너 고정 시 사용
--sw 스타일 참조의 강도 조절 0 ~ 1000
(기본 100)		 --sref와 함께 사용. 무드보드와 함께 사용은 불가능
--cref Character Reference
인물 일관성 유지		 이미지 URL 동일 모델로 여러 컷의 룩북을 만들 때 필수
--cw 캐릭터 참조의 범위 설정 0 ~ 100
(기본 100)		 0이면 인물의 얼굴 위주, 100이면 의상까지 복사
--p Personalization
개인 취향 반영

or

Moodboard
개인 취향 반영		 (자동 또는 코드) 프로필 코드 사용 시 나의 선호 이미지 이력을 기반으로 최적화된 화풍 적용. 무드보드 사용 시 무드보드 구성 이미지를 기반으로 최적화된 화풍 적용
--iw 이미지 프롬프트의 비중 설정 0 ~ 2 이미지 주소와 텍스트 프롬프트를 모두 사용할 때 이미지 영향력 결정
