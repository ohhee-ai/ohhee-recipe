React Bits 3D Gallery Portfolio Interaction
AI 이미지, AI 영상, 패션 에디토리얼, 브랜딩, 제품 이미지 등 비주얼 작업물을 일반적인 Grid 방식이 아닌 인터랙티브한 형태로 보여줄 수 있는 웹 갤러리 UI 레퍼런스입니다.

모두 React Bits의 무료 Components에서 확인할 수 있으며, Claude Code / Codex 등의 코딩 에이전트에 복사→붙여넣기 할 수 있는 코드를 제공합니다.
01

Dome Gallery

Description

수많은 이미지가 하나의 거대한 반구형 공간을 이루도록 배치되는 3D 이미지 갤러리. 사용자가 마우스나 드래그를 이용해 여러 방향으로 이미지 공간을 탐색할 수 있습니다.

AI Creator 활용

  • 전체 작품 Archive
  • AI 이미지 포트폴리오
  • 패션·뷰티 에디토리얼
  • 세계관 기반 포트폴리오
