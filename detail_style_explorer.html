01

Style Explorer에서 원하는 스타일 찾는 방법

Style Explorer는 미드저니 안에서 다양한 --sref 스타일 코드를 눈으로 탐색하고, 바로 테스트하거나 저장할 수 있는 기능입니다. 스타일 코드는 이미지의 주제보다 색감, 매체감, 질감, 조명, 분위기를 일관성 있게 반복 적용하는 데 유용합니다.

1-1. 기본 흐름
Explore Page 접속 ↓ Styles 탭 열기 ↓ Random / Popular / 검색어로 스타일 탐색 ↓ 마음에 드는 스타일 코드 클릭 ↓ 예시 이미지 갤러리 확인 ↓ Try Style / Copy / Search similar / Like 중 선택 ↓ 같은 테스트 프롬프트로 비교 ↓ 최종 후보 코드를 아카이빙
1-2. 먼저 원하는 스타일 축을 정하기

Style Explorer에서 무작정 예쁜 이미지를 찾으면 시간이 많이 걸립니다. 먼저 어떤 축의 스타일이 필요한지 정하면 탐색이 훨씬 빨라집니다.

스타일 축스스로에게 물어볼 질문검색어 예시
매체감사진인가, 그림인가, 3D인가?photographic, watercolor, oil painting, 3D
색감따뜻한가, 차가운가, 흑백인가?pastel, monochrome, neon, warm, muted
질감매끈한가, 거친가, 종이/실/필름 느낌인가?grain, paper, embroidery, sketch, canvas
조명자연광인가, 영화광인가, 네온인가?cinematic, soft light, noir, studio, neon
장르애니, 패션, 제품, 판타지 등 무엇에 가까운가?anime, fashion, product, fantasy, editorial, collage art
구도미니멀한가, 대칭인가, 클로즈업인가?minimal, poster, portrait, symmetry, close-up
1-3. 넓은 검색어로 시작하기

처음부터 너무 구체적인 단어를 넣기보다, 넓은 키워드로 후보를 많이 본 뒤 좁혀가는 방식이 좋습니다.

추천 검색어 키워드
photographic / cinematic / anime / illustration watercolor / oil painting / 3D / minimal retro / noir / fashion / product / surreal
추천 탐색 방식
1. 큰 키워드로 검색한다. 2. 마음에 드는 코드 10개를 후보로 저장한다. 3. Search 기능으로 결이 비슷한 다른 코드도 확인한다. 4. 리스트업한 스타일은 같은 테스트 프롬프트로 모두 비교한다. 5. 잘 맞는 용도와 약점을 기록한다. 6. 최종 후보 2-3개만 남긴다.
1-4. 같은 테스트 프롬프트로 비교하기

스타일 코드를 비교할 때는 반드시 같은 프롬프트를 사용해야 합니다. 프롬프트가 바뀌면 결과 차이가 스타일 때문인지 주제 때문인지 알기 어렵습니다.

인물 스타일 테스트용
a woman sitting in a quiet cafe, half body portrait, soft window light --ar 4:5 --v 7
제품 스타일 테스트용
a glass perfume bottle on a simple table, studio lighting, clean background --ar 4:5 --v 7
02

두 개 이상의 스타일을 함께 쓰는 방법

SREF 스타일은 한 개만 쓰는 것이 안정적이고 예측 가능하지만, 두 개 이상을 함께 섞으면 더 독특한 이미지를 만들 수 있습니다. 핵심은 베이스 스타일 하나 + 포인트 스타일 하나로 생각하는 것입니다.

2-1. 기본 혼합
문법
[프롬프트] --sref A B --sw 100 --s 100 --v 7
예시
a woman reading in a cafe --sref 111111111 222222222 --sw 100 --s 100 --v 7
2-2. 가중치 혼합

가중치를 주면 어떤 스타일을 더 강하게 반영할지 조절할 수 있습니다.

A를 베이스로
[프롬프트] --sref A::2 B::1 --sw 100 --s 100 --v 7
B를 베이스로
[프롬프트] --sref A::1 B::2 --sw 100 --s 100 --v 7
2-3. 반드시 단독 테스트 후 섞기
테스트목적예시
A 단독A 스타일의 핵심 요소 파악--sref A
B 단독B 스타일의 핵심 요소 파악--sref B
A+B 균등두 스타일이 자연스럽게 섞이는지 확인--sref A B
A 강하게A를 베이스로 사용할 수 있는지 확인--sref A::2 B::1
B 강하게B를 베이스로 사용할 수 있는지 확인--sref A::1 B::2
혼합 약하게스타일 과잉을 줄일 수 있는지 확인--sw 50 --s 80 --raw
혼합 강하게아트워크로 밀어붙일 수 있는지 확인--sw 250 --s 250
03

두 개 이상의 스타일을 섞었을 때 아웃풋 예측법

스타일 혼합은 정확한 수식으로 예측할 수는 없습니다. 하지만 스타일을 몇 가지 축으로 분해하면 결과를 상당히 잘 예상할 수 있습니다.

3-1. 스타일 분해표
축확인할 것결과에 미치는 영향
매체사진, 유화, 수채화, 3D, 자수, 판화이미지가 어떤 재료로 만들어진 것처럼 보이는지 결정
색감파스텔, 네온, 흑백, 저채도, 웜톤전체 팔레트와 분위기를 결정
조명자연광, 스튜디오, 영화광, 네온, 촛불입체감, 감정, 장면성을 결정
질감종이, 캔버스, 실, 필름 그레인, 금속표면의 촉각적 느낌을 결정
구도중앙, 대칭, 클로즈업, 넓은 여백화면 배치와 시선 흐름을 결정
디테일미니멀, 정교함, 장식성, 노이즈복잡도와 완성도 인상을 결정
무드귀여움, 고급스러움, 어두움, 몽환적감정적 방향을 결정
3-2. 예측 공식
결과=프롬프트 내용
+스타일 A의 강한 축
+스타일 B의 강한 축
--sw=스타일 강도 조절
--s=미드저니의 예술적 해석 강도
--raw=미드저니의 자동 미학을 줄임
seed=변동성 (비교 시 고정 권장)
3-3. 강한 축이 이긴다

두 스타일을 섞으면 보통 더 강한 시각 신호가 먼저 드러납니다.

상황결과 예측
A는 색감이 강하고 B는 질감이 강함A의 색감 + B의 질감이 섞일 가능성
A는 사진이고 B는 자수사진적 구도에 공예 질감이 붙거나, 반대로 일러스트화될 수 있음
A와 B 모두 네온 색감네온 팔레트가 매우 강해질 가능성
A와 B 구도가 모두 중앙 대칭결과도 중앙 정렬과 대칭이 반복될 가능성
A는 미니멀, B는 맥시멀중간값이 나오거나 한쪽이 다른 쪽을 이길 가능성
04

스타일 혼합 결과 예측표

스타일 A스타일 B예상 결과
실사 사진시네마틱 필름현실적인 영화 스틸컷
실사 사진수채화반실사 + 부드러운 페인터리 질감
실사 사진자수사진 구도에 실/천 질감이 섞이거나 공예풍 일러스트로 기울 수 있음
유화바로크어두운 명암, 두꺼운 붓질, 극적인 인물화

05

스타일 섞을 때 잘 나오는 조합

5-1. 같은 매체 + 다른 무드

가장 안정적인 조합입니다. 매체가 같기 때문에 결과가 크게 흔들리지 않고, 분위기만 확장됩니다.

수채화 계열
watercolor + children's book
유화 계열
oil painting + baroque
사진 계열
photographic + cinematic
3D 계열
3D render + toy design
5-2. 같은 색감 + 다른 매체

색감이 같으면 매체가 달라도 통일감이 생깁니다.

파스텔 계열
pastel watercolor + pastel embroidery
웜톤 계열
warm cinematic + warm editorial
모노크롬 계열
monochrome ink + monochrome comic
5-3. 베이스 스타일 + 포인트 스타일 ★ 실무 추천

실무에서 가장 추천하는 방식입니다. 베이스 스타일에 ::2 가중치를 주고 포인트에 ::1을 주면 조절이 쉬워집니다.

조합 예시
베이스: photographic + 포인트: vintage grain 베이스: watercolor + 포인트: gold ornament 베이스: minimal poster + 포인트: art deco
프롬프트 예시
a perfume bottle on an ivory background --sref 111111111::2 222222222::1 --sw 100 --s 100 --v 7
06

스타일 섞을 때 불안정한 조합

주의: 아래 조합은 매력적인 하이브리드가 나오기도 하지만, 결과가 들쭉날쭉할 수 있습니다. 시드를 고정하고 여러 번 테스트하세요.
6-1. 매체가 너무 충돌하는 경우
photorealistic + cross stitch 3D render + ink wash pixel art + oil painting
6-2. 색감이 정반대인 경우

결과가 중간색으로 뭉개지거나, 한쪽 스타일이 다른 쪽을 잡아먹을 수 있습니다.

warm vintage + cold cyberpunk pastel cute + dark noir earth tone minimal + neon maximal
6-3. 구도가 정반대인 경우

화면 구성이 애매해질 수 있습니다.

minimal centered layout + chaotic collage close-up portrait + wide landscape poster symmetrical design + documentary candid
07

혼합 스타일 예측 체크리스트

질문Yes일 때No일 때
두 스타일의 매체가 비슷한가?안정적하이브리드/불안정 가능
색감이 비슷한가?통일감 있음한쪽 색이 우세하거나 중간톤
조명 방향이 비슷한가?자연스러움이상한 조명 가능
구도 성향이 비슷한가?예측 쉬움프레이밍이 흔들릴 수 있음
하나를 베이스로 정했는가?조절 쉬움결과가 랜덤해지기 쉬움
--seed로 비교했는가?차이 분석 가능비교가 어려움
--sw를 단계별로 테스트했는가?최적점 찾기 쉬움너무 약하거나 과할 수 있음
08

추천 테스트 매트릭스

스타일을 제대로 비교하려면 같은 기준 프롬프트로 여러 값을 순서대로 테스트합니다.

기준 프롬프트
a woman reading in a quiet cafe, half body portrait, soft window light --ar 4:5 --v 7
테스트프롬프트 뒤에 붙일 값목적
A 단독--sref A --sw 100 --s 100A의 순수 성향 확인
B 단독--sref B --sw 100 --s 100B의 순수 성향 확인
A+B 균등--sref A B --sw 100 --s 100두 스타일의 기본 혼합 확인
A 강하게--sref A::2 B::1 --sw 100 --s 100A를 베이스로 쓸 수 있는지 확인
B 강하게--sref A::1 B::2 --sw 100 --s 100B를 베이스로 쓸 수 있는지 확인
혼합 약하게--sref A B --sw 50 --s 80 --raw과한 스타일을 줄인 결과 확인
혼합 강하게--sref A B --sw 250 --s 250아트워크 방향으로 확장 확인
팁: 각 테스트마다 --seed 값을 동일하게 고정하면, 스타일 차이만 순수하게 비교할 수 있습니다.
