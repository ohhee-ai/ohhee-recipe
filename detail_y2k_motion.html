03

가장 간단한 시작 프롬프트

레퍼런스 이미지 없이, 닉네임과 메인 키워드만 바꿔 사용할 수 있는 최소 프롬프트입니다.

Prompt — 간단 버전 / ChatGPT 
닉네임: [닉네임]
메인 키워드: [키워드]

첨부한 이미지와 영상을 활용해 2000년대 웹페이지와 Windows 팝업을 연상시키는 Y2K 모션그래픽을 만들어줘.

[닉네임]과 [키워드]를 메인 타이틀로 사용하고, 첨부한 피사체의 외형은 바꾸거나 새로 생성하지 말아줘. 브라우저 접속, 이미지 창 전환, 픽셀 아이콘, 로딩 바, 마우스 커서, 여러 팝업이 연속으로 열리는 장면을 포함해줘.

핑크 중심의 통일된 UI 디자인으로 제작하고, 모든 창의 모서리·상단바·최소화·최대화·닫기 버튼과 로고 형태를 일관되게 유지해줘.

전체 길이는 10초, 60fps로 제작해줘. 4:5(1080×1350)와 16:9(1920×1080)는 각각 화면에 맞게 재배치하고 단순 크롭하지 말아줘. H.264 MP4로 출력해줘.
04

결과를 더 정확하게 만드는 상세 프롬프트

에셋 역할, 연출 순서, 디자인 규칙까지 명시한 전체 스펙 프롬프트입니다.

Prompt — 상세 버전 / ChatGPT 
첨부 에셋을 직접 사용해 [닉네임]의 Y2K 웹페이지형 모션그래픽을 제작해줘.

핵심 정보
- 닉네임/브랜드명: [닉네임]
- 메인 키워드: [키워드]
- 컬러: [메인 컬러]
- 무드: 2000년대 인터넷, Windows UI, 픽셀, 팝업, 글로시 크롬
- 길이: [길이]초
- 출력: 4:5 1080×1350 / 16:9 1920×1080 / 60fps / H.264 MP4

에셋 사용
- 01_main.png: 대표 장면
- 02_member_a.png, 03_member_b.png: 갤러리 창
- 04_feature.png: 연결 완료 장면
- 05_group.png 또는 group_video.mp4: 시작과 메인 웹페이지 장면
- popup_center.mp4: 무한 팝업 장면의 중앙 영상
- exit_background.mp4: 종료 확인 창 뒤의 영상
- bgm.mp3: 지정한 하이라이트 구간 사용

연출 순서
1. 컴퓨터가 부팅되고 사이트에 접속하는 인트로
2. 브라우저 안에 대표 이미지와 [닉네임] 로고 등장
3. 여러 이미지 창이 차례로 열리는 갤러리
4. CONNECTION COMPLETE 메시지와 알림창
5. 메인 웹페이지 안에서 대표 영상 재생
6. 중앙 영상을 둘러싸며 팝업이 빠르게 증식
7. "Do you want to disconnect?" 창 등장
8. 커서가 YES에 접근할 때 창이 네 번 피해서 이동
9. 마지막에는 연결된 상태로 종료

디자인 규칙
- 첨부 이미지의 인물·제품·캐릭터를 재생성하거나 변형하지 말 것
- 얼굴과 로고가 UI에 가리지 않게 배치할 것
- 모든 창의 모서리 반경, 테두리 두께, 타이틀바, 버튼 모양을 동일하게 유지할 것
- [닉네임] 로고의 형태와 색을 모든 장면에서 동일하게 유지할 것
- 중요한 텍스트는 배경과 분리되도록 창, 반투명 패널 또는 단색 영역 위에 배치할 것
- 4:5와 16:9를 각각 별도 레이아웃으로 제작할 것
- BGM과 효과음은 별도 트랙으로 관리하고 최종 단계에서 믹스할 것

먼저 장면 구성과 타임라인을 제안한 뒤 제작하고, 완성 후 해상도·길이·프레임레이트·오디오 포함 여부를 검증해줘.

실제 제작 워크플로우

STEP 1
콘셉트를 두 단어로 고정하기

처음부터 세부 디자인을 모두 결정할 필요는 없습니다. 닉네임과 메인 키워드만 먼저 정하세요.
이 두 단어를 로고, 주소창, 파일명, 팝업 메시지, 상태 표시줄에 반복하면 짧은 영상도 하나의 브랜드처럼 보입니다.

예시
닉네임: OHHEE
메인 키워드: DIGITAL DREAM
STEP 2
에셋의 역할을 지정하기

이미지를 한꺼번에 첨부하는 것보다 역할을 함께 적는 것이 중요합니다.

역할 지정 예시
1번은 메인 이미지
2번과 3번은 갤러리 이미지
4번은 연결 완료 장면
5번은 시작과 마지막에 사용할 대표 이미지
인물 교체 예시
처음과 7.5~10초의 대표 이미지에는 단체 이미지를 사용하고,
3.3~5.8초의 세 번째 이미지 창에는 새로 첨부한 인물을 넣어줘.
나머지 장면과 타이밍은 유지해줘.
STEP 3
장면과 타임라인 설계하기

OHHEE 완성본의 타임라인 구성입니다.

시간장면핵심 연출

STEP 4

여러 장면을 따로 만들면 창 디자인이 조금씩 달라지기 쉽습니다. 제작 전에 미리 고정하세요.

  • 창 모서리의 둥근 정도
  • 테두리 두께와 색

  • 최소화·최대화·닫기 버튼의 순서와 모양
  • 본문 글꼴과 픽셀 글꼴
  • 버튼의 입체 효과 / 로고의 비율, 광택, 외곽선
  • 커서 크기와 그림자

07

ChatGPT와 작업할 때 추천하는 대화 순서

한 번의 긴 프롬프트보다 단계별로 나눠 요청하면 수정이 훨씬 쉬워집니다.

  1. 콘셉트 제시: 닉네임, 키워드, 색상, 무드, 길이
  2. 핵심 에셋 첨부: 메인 이미지와 추가 이미지
  3. 첫 버전 제작: 우선 한 비율로 디자인과 움직임 확인
  4. 인물·제품 교체: 장면명과 시간을 지정해서 부분 수정
  5. 새 장면 추가: 중앙 영상, 무한 팝업, 인터랙션 등
  6. 디자인 통일: 버튼, 모서리, 로고를 기존 장면과 비교
  7. 오디오 교체: 사용할 구간과 싱크 포인트 지정
  8. 다른 비율 제작: 단순 크롭이 아닌 별도 레이아웃 요청
  9. 최종 검증: 길이, 해상도, fps, 오디오, 이미지 순서 확인
수정 요청에는 항상 바꿀 것과 유지할 것을 함께 적는 것이 핵심입니다.
08

최종 검수 체크리스트

이미지와 영상
  • 모든 이미지가 지정한 순서로 등장한다
  • 첨부하지 않은 얼굴이나 제품이 새로 생성되지 않았다
  • 얼굴, 로고, 핵심 제품이 잘리지 않았다
  • 정지 이미지를 영상으로 교체한 구간이 정확하다
  • 영상의 종횡비가 왜곡되지 않았다
UI와 디자인
  • 모든 창의 모서리 모양이 같다
  • 최소화·최대화·닫기 버튼이 같은 디자인이다
  • 로고의 글자 형태와 광택이 장면마다 같다
  • 텍스트가 복잡한 배경 위에 직접 놓이지 않았다
  • 4:5와 16:9 모두 안전 영역을 지킨다
모션
  • 팝업이 자연스럽게 늘어나며 중앙 피사체를 과도하게 가리지 않는다
  • 종료 창이 커서를 정확히 네 번 피한다
  • 창이 화면 밖으로 잘리지 않는다
  • 장면 전환이 음악의 박자 또는 효과음과 맞는다
오디오와 출력
  • BGM 하이라이트가 원하는 지점에서 시작한다
  • 클릭음과 팝업 효과음이 BGM과 함께 들린다
  • 음량이 찢어지거나 지나치게 크지 않다
  • 최종 영상에 오디오가 포함되어 있다
  • 해상도, 길이, fps, 코덱이 요청과 일치한다
09

자주 생기는 문제와 해결 문장

문제요청 문장
인물이 다른 사람처럼 변함"첨부 이미지를 직접 사용하고 얼굴을 재생성하지 말아줘."
창 디자인이 장면마다 달라짐"기존 장면의 창 컴포넌트를 그대로 재사용해줘."
16:9에서 내용이 잘림"단순 크롭하지 말고 가로 전용 좌표로 다시 배치해줘."
음악 교체 후 효과음이 사라짐"BGM만 교체하고 기존 SFX 트랙은 유지해줘."
텍스트가 배경에 묻힘"텍스트 뒤에 불투명한 창 또는 그라데이션 패널을 넣어줘."
팝업이 얼굴을 가림"팝업 생성 영역을 중앙 피사체 바깥쪽으로 제한해줘."
특정 장면만 바꾸고 싶음"해당 구간만 교체하고 나머지 프레임과 오디오는 그대로 유지해줘."
10

제작 방식 메모

  • 2D Canvas 기반으로 브라우저, 창, 버튼, 로고, 커서 애니메이션 제작
  • 첨부 이미지와 영상을 프레임 안에 직접 합성 (이미지 생성: 미드저니, 영상 생성: 그록)
  • 짧은 원본 영상을 이미지 시퀀스로 변환해 안정적으로 재생
  • 60fps로 프레임 렌더링 후 FFmpeg로 H.264 인코딩 및 오디오 합성
  • BGM과 SFX를 분리해 교체 가능한 구조로 관리
  • 4:5와 16:9에 각각 별도의 레이아웃 좌표 사용
AI 영상 생성만으로 전체를 만드는 방식보다, UI와 텍스트처럼 정확성이 중요한 요소를 코드 기반 모션그래픽으로 만들고 첨부 에셋을 직접 합성하면 인물과 로고의 일관성을 더 안정적으로 유지할 수 있습니다.
