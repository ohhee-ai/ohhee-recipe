01

랜딩 페이지 레퍼런스 사이트 서치

이번 작업의 목표는 단순한 홈페이지가 아니라, 가상 브랜드 MONTEVE의 무드와 제품 세계관을 보여주는 에디토리얼형 랜딩페이지를 제작하는 것이었습니다. MONTEVE는 여성복/남성복과 향수를 함께 다루는 브랜드로, 시간이 지나도 사용할 수 있는 영속성 있는 브랜드 랜딩페이지를 목표로 했습니다.

  • 제품 구매가 가능한 페이지지만 너무 상업적으로 보이지 않을 것
  • 룩북과 브랜드북의 분위기를 함께 가질 것
  • 이미지·타이포그래피·여백이 미니멀하고 고급스러운 브랜드 이미지로 연결될 것
  • 추후 실제 웹사이트나 쇼핑몰로 확장 가능한 구조일 것
참고 레퍼런스로 픽한 사이트: marionparke.com
단, 고급 인터랙션이 들어간 사이트를 100% 복제하는 작업이나 Webflow/Framer처럼 복잡한 CMS 구조의 사이트는 클로드 코드·코덱스 없이 GPT 만으로 작업하기 어려울 수 있습니다.

02

챗GPT에서 프롬프트 입력하고 이미지 첨부하기

챗GPT에서 아래 프롬프트를 입력하고 준비해 둔 이미지들을 첨부합니다. 대괄호 안 부분은 내 브랜드·레퍼런스에 맞게 수정하세요.

메인 랜딩페이지 생성 프롬프트

나는 [브랜드명]이라는 브랜드의 랜딩페이지를 만들고 싶어.
레퍼런스 사이트 주소와, 랜딩 페이지에 들어갈 이미지는 같이 첨부할게.
이미지의 수량이 부족할경우 일단 place holder 로 처리해줘.

브랜드 무드:
[예: 미니멀, 조용한 럭셔리, 여성복, 향수, 에디토리얼]

참고하고 싶은 사이트의 주소와 구조: [사이트 주소]
[예: 럭셔리 커머스 랜딩페이지, 룩북형 브랜드 사이트]

페이지 구성:
1. 상단 안내 바
2. 헤더 / 로고 / 메뉴
3. 히어로 섹션
4. 제품 카드
5. 브랜드 철학
6. 룩북 그리드
7. 뉴스레터
8. 푸터

디자인 조건:
- 배경색: [HEX 컬러 코드]
- 로고는 넓은 자간의 산세리프
- 전체적으로 미니멀하고 고급스럽게
- 모바일 반응형 포함
- HTML 파일 하나로 실행 가능하게

위 조건으로 index.html 페이지를 만들어줘.

레퍼런스 사이트 분석 프롬프트 (다른 형식의 사이트에 맞춤 적용할 때)

이 [사이트 주소] 사이트를 레퍼런스로 참고하여
브랜드 [브랜드명]의 랜딩페이지를 만들어보고 싶어.
위 사이트의
1. 전체 구조
2. 핵심적인 시각 요소
3. 레이아웃 특징
4. 텍스트 스타일
5. 인터랙션 요소
6. 디자인 키워드
를 분석해줘.
이 프롬프트는 MONTEVE 브랜드에 맞춤 셋팅된 것입니다. 다른 형식의 사이트로 생성하시길 원하시는 경우 페이지 구성과 디자인 조건 부분을 수정해서 사용하세요. 위 분석 프롬프트로 먼저 분석한 뒤 메인 프롬프트를 수정하면 더 정확한 결과를 얻을 수 있습니다.
