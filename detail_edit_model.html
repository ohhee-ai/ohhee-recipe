2026. 08. 28

드디어 미드저니에 이미지 편집 기능이 생겼어요. 텍스트로 수정 지시를 내리거나, 여러 이미지를 합쳐 새 이미지를 만들고, 특정 부분만 골라서 바꿀 수도 있습니다. 기존 생성형 AI들과 달리 무드보드·퍼스널라이제이션까지 편집에 붙여 쓸 수 있다는 게 포인트예요.

01

텍스트로 이미지 수정

프롬프트에 원하는 변화를 쓰면 이미지를 직접 편집해줘요. "배경을 밤하늘로 바꿔줘" 같은 식으로요.

02

이미지 최대 4장 합성

참조 이미지를 4장까지 동시에 넣어 새 이미지를 뽑을 수 있어요. 기존 옴니레퍼런스보다 훨씬 유연해졌어요.

03

인페인팅 & 아웃페인팅

마음에 안 드는 부분만 골라 수정하거나, 캔버스를 더 넓게 확장하는 것도 가능해요.

04

퍼스널라이제이션 · 무드보드 · sref

편집 모델에서도 개인 프로필, 무드보드, sref를 그대로 쓸 수 있어요. 다만 이 버전에서는 추가 설명 프롬프트를 같이 입력하는 게 결과가 더 좋았어요.

How to use

편집 모델 시작하는 방법

  • ① 프롬프트 창 아래 프롬프트에 첨부 영역으로 이미지를 드래그해서 올려요.
  • ② 기존에 만든 이미지가 있다면, 라이트박스로 열고 오른쪽 하단 편집 버튼을 눌러요.
  • ③ 처음부터 편집용 이미지를 올리려면 왼쪽 Edit 탭에서 업로드하면 돼요.
  • ④ 디스코드를 쓴다면 프롬프트 끝에 --edit 이미지URL 형태로 입력해요.
