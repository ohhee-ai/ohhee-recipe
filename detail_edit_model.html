📌 2026. 08. 28 공개

미드저니 첫 번째 V8.2 이미지 편집 모델이 공개됐습니다. 텍스트 지시만으로 이미지를 수정하거나, 최대 4장의 참조 이미지를 합성하고, 원하는 영역만 인페인팅·아웃페인팅할 수 있습니다.

01

텍스트 지시로 이미지 편집

프롬프트로 원하는 변경 사항을 설명하면 이미지를 직접 수정합니다.

02

최대 4개 이미지 참조 합성

옴니레퍼런스를 대체하여 최대 4장의 참조 이미지로 새 이미지를 생성합니다.

03

인페인팅 & 아웃페인팅

이미지의 특정 영역만 수정하거나 캔버스를 원하는 방향으로 확장합니다.

04

퍼스널라이제이션 · 무드보드 · sref

개인 취향 프로필, 무드보드, 스타일 레퍼런스를 편집 모델에서도 활용 가능합니다. 이 버전에서는 추가 프롬프트 설명을 함께 입력하면 더 효과적입니다.

How to use

편집 모델 사용 방법

  • ① 드래그 업로드 — 미드저니 프롬프트 창의 "프롬프트에 첨부" 영역으로 이미지를 드래그합니다.
  • ② 라이트박스 편집 — 생성된 이미지를 라이트박스로 열고 오른쪽 하단의 편집 버튼을 클릭합니다.
  • ③ 편집 탭 — 왼쪽의 Edit 탭을 클릭하고 직접 이미지를 업로드합니다.
  • ④ 디스코드 — 프롬프트 끝에 --edit url... 형식으로 입력합니다.

Note

피드백 채널

예상대로 동작하지 않는 이미지가 있으면 라이트박스 오른쪽의 😞 이모지를 누르거나, 라이트박스에서 이미지를 열어 Job ID / URL을 공유해 주세요.

UI 개선 아이디어나 모델의 엣지케이스는 디스코드 #ideas-and-features 채널에 남겨주세요. 편집 결과물 공유는 #edit-showcase에서 가능합니다.
